```text
crystal_lamp/
|-- platformio.ini        # Плата, библиотеки, контакты и лимиты
|-- README.md             # Сборка, прошивка и управление
|-- wiring.svg            # Схема подключения
|-- docs/
|   |-- STRUCTURE.md      # Этот файл
|   `-- WIRING.md         # Электрика и питание
`-- src/
    |-- main.cpp          # setup(), loop(), FastLED и датчик
    |-- config.h          # Режимы и значения по умолчанию
    |-- globals.h         # Общие переменные состояния
    |-- storage.h         # Хранение режима в EEPROM
    |-- shake.h           # Прерывание и фильтрация KY-020
    `-- modes/
        |-- modes.h       # Диспетчер режимов
        `-- crystal.h     # Эффекты лампы
```

## Поток управления

1. Прерывание `D2` отмечает каждый переход HIGH/LOW от KY-020.
2. Первый фронт нового потока движения сразу вызывает `selectNextMode()`.
3. Последующие фронты игнорируются до 500 мс полной тишины.
4. После debounce датчик повторно готов к смене режима.
5. Выбранный режим сохраняется в EEPROM.
6. `updateMode()` обновляет активный эффект каждые 10 мс.
7. FastLED ограничивает расчетный ток значением `POWER_LIMIT_MA`.

## Как добавить эффект

1. Добавить значение в `enum Mode` в `src/config.h`.
2. Добавить имя, скорость и яркость в массивы пресетов.
3. Реализовать функцию эффекта в `src/modes/crystal.h`.
4. Добавить вызов в `src/modes/modes.h`.

`MODE_COUNT` должен оставаться последним элементом перечисления. После смены
формата сохраняемых данных увеличьте `SETTINGS_VERSION`.

## Что осталось от fireplace

- PlatformIO и Arduino framework;
- FastLED и разнесение эффектов по модулям;
- сохранение выбранного режима между перезапусками.

WiFiManager, HTTP-сервер и веб-страницы удалены, поскольку фактическая плата
на ATmega328P не имеет Wi-Fi. Вместо `Preferences` ESP32 используется EEPROM.
